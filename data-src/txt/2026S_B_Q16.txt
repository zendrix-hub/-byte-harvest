                 The program converts the code point of a Unicode character to a 2-byte UTF-8 encoding. In
                 this question, “(16)” after a numerical value indicates a hexadecimal value. Each Unicode
                 character is given an integer value that is known as a code point. A character with a code
                 point that ranges from 80(16) to 7FF(16) is encoded to a 2-byte value as below.
                 Let the bit pattern with a 2-byte length be:  110xxxxx  10xxxxxx. The underlined 11 “x”
                 positions in the bit pattern store the 11-bit code point. The code point is justified to the right,
                 and  0  is stored in any leftover “x” positions. This 2-byte value is the encoded result. For
                 instance, when the code point AE(16) for Registered Sign character “®” is represented in
                 binary, it is  10101110. When this is stored right-justified in the “x” positions in the bit
                 pattern above, it is  110xxx10  10101110. When  0  is stored in the three leftover “x”
                 positions, the UTF-8 encoding for Registered Sign character “®”  11000010 10101110  is
                 obtained. In decimal form, this corresponds to  {194, 174}.
                 The function  encode  converts a Unicode code point that is passed as an argument to UTF-8
                 encoding, and returns an integer array that stores it one byte per element from the start of the
                 array. It is assumed that only an integer value that ranges from 80(16) to 7FF(16) is passed to
⟦code⟧          encode  as an argument.
